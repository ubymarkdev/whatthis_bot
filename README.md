# WHATTIS_BOT | BOT PARA FILTRADO DE PROSPECTOS CALIFICADOS

# Descripción
Herramienta desarrollada para contactar instantaneo con el prospecto en las primeras interacciones,
una vez el sistema detecta intenciones como cotización/precios/costo o similares, el bot "duerme" y entra la interacción 
humana.

# Problema 
Debido a las amplias campañas disigtales en muchos canales de distribución, el equipo de atención al cliente se vio superado por el número 
de mensajes y chats, por lo que surge la necesidad de hacer un filtrado automatico de preguntas más frecuentes en las cuales los asesores invertían mucho tiempo 
para no terminar de concretar la compra.

# Solución y funcionalidades 
Este bot es capaz de filtrar prospectos, contestando chats de manera inmediata dudas frecuentes, hasta que muestren intención 
de compra, aquí el bot se apaga y entra la interacción humana.
El flujo es el siguiente:  
  1. Entra un mensaje a la cuenta de Whatsapp.
  2. Según el contenido, el bot decide que respuesta dar.
  3. Determina si es necesaria la intervención humana, ya sea por intención de compra o por una solicitud muy especifica.
  4. El bot duerme y entra la interacción humana.
